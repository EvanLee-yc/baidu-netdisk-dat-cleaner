# 百度网盘 .dat 视频批量清理器

一个跑在百度网盘网页版上的脚本，用来**批量删除 `.dat` 格式的视频文件**，
并且**不受网页搜索「一次最多 500 条」的限制**。

主文件：`baidu-netdisk-dat-cleaner.user.js`

---

## 一、先说调研结论

在 GitHub 上检索过 `百度网盘 删除` / `百度网盘 清理 脚本` / `pan.baidu.com userscript delete` /
`baidupan api delete` 等关键词，**没有找到任何「网页版自动删除 .dat / 批量清理」的成品脚本**。

检索到的都是另一类项目，用途不同：

| 项目 | 实际用途 |
| --- | --- |
| `syhyz1990/baiduyun`、`wwqgtxx/baiduyun` | 油猴脚本，网盘**下载**助手/加速 |
| `peterq/pan-light`、`qjfoidnh/BaiduPCS-Go` | 第三方客户端，**下载**为主 |
| `yuantuo666/baiduwp-php` | 解析**分享链接**的直链 |
| `masx200/fetch-baidu-pan-files-api` | Node.js 批量清理**重复文件**（最接近，但不是浏览器脚本、也不针对 .dat） |

上面最后一个项目把网盘的真实接口参数记录得很完整，本脚本的接口调用方式即依据它核对过。

## 二、加载方式（二选一）

### 方式 A：油猴脚本（推荐，长期可用）

1. 浏览器安装 Tampermonkey（篡改猴）。
2. 打开 Tampermonkey 面板 → 「添加新脚本」，把 `baidu-netdisk-dat-cleaner.user.js`
   全部内容粘进去，Ctrl+S 保存。
3. 刷新 `https://pan.baidu.com/disk/main`，右下角会出现控制面板。

### 方式 B：控制台临时运行

1. 打开并登录 `https://pan.baidu.com/disk/main`。
2. F12 → Console，把整个 `.user.js` 文件内容粘进去回车。
3. 同样会出现右下角面板；也可以直接敲 `bdcl.run(true)` 开始扫描。

## 三、使用步骤

**第一步：改配置。** 打开脚本顶部的 `CONFIG`，最常用的三个：

```js
rootDir: '/',                 // 只想扫某个文件夹就写 '/我的资源/video'
onlyCategoryVideo: true,      // 只删网盘判定为「视频」的 .dat，防止误删同名文件
excludePaths: ['/重要资料'],   // 路径里包含这些字符串的目录直接跳过
```

**第二步：试运行。** 点「试运行扫描」→ 只看清单和体积，**不会删任何东西**。

**第三步：核对。** 点「打印删除清单」，控制台会列出每个待删文件的完整路径和体积，
同时自动复制到剪贴板。重点核对有没有不该删的路径。

**第四步：删除。** 点「开始删除」→ 会弹确认框报出总数和总体积 → 确认后才真正开始。

> 面板上的「开始删除」是**强制执行**删除，不受 `CONFIG.dryRun` 限制；
> 而 `CONFIG.dryRun` 只影响你在控制台直接调用 `bdcl.run()` 时的默认行为。
> 真正拦住误删的是那个确认框和第三步的清单核对。

**第五步：万一删错了。** 去网盘「回收站」恢复，默认保留约 10 天。

## 四、为什么能绕开「搜索最多 500 条」

网页版搜索框走的是 `/api/search` 接口，单次返回条数被限制在 500 条，
所以文件一多，用搜索根本搜不全，也就删不干净。

本脚本**完全不用搜索接口**，改走网盘的目录列表接口：

```
GET /api/list?dir=<目录>&page=<页码>&num=1000&...
```

- 单页最多 1000 条，靠 `page` 翻页，直到某页返回条数少于 1000 为止
  → 一个目录下的**全部**文件都能拿到，不受 500 条限制；
- 再对子目录递归，逐层把整个网盘（或指定目录）走完；
- 走完后本地按扩展名 + 文件类型过滤，最后批量调删除接口。

删除接口就是网页版自己在用的那个：

```
POST /api/filemanager?async=2&opera=delete&onnest=fail&channel=chunlei&web=1&app_id=250528&...
body: filelist=<URL 编码的 JSON 路径数组>
```

**筛选规则**（`checkFile()`）三条同时满足才会被删：

1. 不是目录；
2. 文件名以 `.dat` 结尾（不区分大小写）；
3. `category === 1`，即网盘自己把它归类为「视频」。

第 3 条是关键保护：`.dat` 也可能是别的软件的数据文件，用网盘自己的类型判定能挡掉大部分误删。
如果确实想连非视频的 `.dat` 一起删，把 `onlyCategoryVideo` 改成 `false` 即可。

## 五、可靠性设计

| 场景 | 处理 |
| --- | --- |
| 单次删除数量超限（errno 3） | 自动把这一批拆成两半重试，递归拆分直到成功 |
| `bdstoken` 过期（errno 112） | 自动重新获取 token 后重试同一批 |
| 登录态失效（errno -6） | 立即停止并提示重新登录 |
| 网盘要求身份验证（errno 132） | 立即停止，提示去网页手动验证一次 |
| 任务队列未清空（errno 111） | 等 5 秒后重试 |
| 文件已不存在（errno -9） | 视为删除成功，不计入失败 |
| 列表/删除请求网络异常 | 按配置次数重试，指数退避 |
| 接口被拖垮的风险 | 分页间 150ms、批次间 `batchDelayMs` 节流 |
| 日志过长卡页面 | 日志区最多保留 800 行 |
| 递归异常深度 | `maxDepth` 上限，默认 64 层 |
| 单次运行量过载 | `maxDelete` 上限，默认 20 万 |

另外脚本暴露了 `window.bdcl`，可以在控制台手动操作：

```js
bdcl.CONFIG.dryRun = false   // 关掉控制台调用的试运行
bdcl.run()                   // 按当前配置扫描 + 删除
bdcl.run(true)               // 强制只扫描
bdcl.printList()             // 打印清单
bdcl.state.matched           // 查看命中的文件数组
```

## 六、风险提示（请务必读）

1. **删除进的是回收站，不是永久删除**，默认保留约 10 天，这是最重要的兜底。
2. **有触发风控的可能。** 短时间大量删除，网盘可能要求身份验证（errno 132）或限制操作。
   脚本遇到 132 会立即停止，不会硬刚。如果频繁出现，把 `batchDelayMs` 调到 2000 以上再试。
3. **不要开着脚本去点网页上的其他操作**，避免和网盘自己的状态管理打架。
4. **不要用 BDUSS 之类的 Cookie 去跑第三方工具**，本脚本全程在你自己浏览器的登录态里跑，
   不导出、不上传任何凭据。
5. 首次使用**一定先试运行**，并且看清楚 `onlyCategoryVideo` 是否符合你的预期。
6. 网盘接口未公开、可能随时变更。若某天脚本失效，多半是接口参数变了，
   用 F12 → Network 抓一次真实请求，对照 `apiList()` / `deleteBatch()` 里的参数改即可。
